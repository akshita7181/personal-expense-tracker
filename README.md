# Personal Expense Tracker

A beginner-friendly command-line application built using Python to record and analyze personal expenses.

## Features

- Add and record expenses
- View all recorded expenses
- Calculate total spending
- View category-wise spending
- Identify the highest expense
- Store expense data using CSV files
- Basic input validation and error handling

## Technologies Used

- Python
- CSV
- File Handling
- Dictionaries
- Functions

## How to Run

1. Install Python.
2. Download or clone the project.
3. Open the project folder in a terminal.
4. Run:

```bash
python expense_tracker.py
```

5. Follow the menu displayed in the terminal.
